# Данные

В проекте используется открытый датасет DANO 2024 для кейса «Т-Банк Путешествия».

Официальная страница с материалами:

https://dano.hse.ru/data2024

Исходный датасет содержит **835 938 строк и 56 признаков** с информацией о заказах авиабилетов и отелей, характеристиках клиентов и потенциальных клиентах.

Исходный CSV-файл не хранится в GitHub из-за большого размера.

При первом запуске Jupyter Notebook датасет автоматически загружается в эту папку из публичного источника DANO.

Файлы исходных данных исключены из Git с помощью `.gitignore`.
